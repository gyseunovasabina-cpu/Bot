Данный проект представляет собой консольного чат-бота, который умеет:

- рекомендовать развлечения по настроению и интересам пользователя;

- поддерживать простой разговор;

- рассказывать шутки;

- показывать «последние новости»;

- предлагать покупку.

Проект создан с целью практики работы с:

- циклами (while);

- условными операторами (if / elif / else);

- функциями;

- разбиением программы на модули (несколько файлов).

Архитектура проекта
Проект разделён на несколько файлов. Каждый файл отвечает за свою часть логики.

chat_bot/

│
├── main.py           # основной файл, запуск бота и меню

├── recommendations.py  # рекомендации развлечений

├── chat.py           # поддержка разговора и шутки

├── info.py           # новости и предложения

└── README.md         # описание проекта
